## Cambio conservado

`--arm64-safe-icf` activa `-faddrsig` al compilar `main` y `--icf=safe` al enlazar. La referencia `--arm64-icf-metadata` genera la misma metadata sin deduplicar. Ambos argumentos requieren `arm64-v8a` y están desactivados por defecto. No se usa `--icf=all`, LTO, fast-math ni relajación de identidad de direcciones.

Se conserva el cuerpo local de cada helper y la información que el compilador tiene sobre sus efectos. El enlazador puede compartir cuerpos idénticos cuya dirección no es significativa. La prueba adversarial conserva distintas dos funciones idénticas cuyas direcciones se guardan en una tabla. [Implementación de safe ICF y metadata en LLVM](https://reviews.llvm.org/D48146).

La aplicación a las copias x87 parte de los [18.194 grupos exactos ya identificados](CPU_PHASE12_X87_STACK_SHIFT_OUTLINE_OFFLINE_2026-10-14.md). Las siete copias ordenadas de 10 bytes y los seis bytes de padding de cada ranura no cambian. No se modifica aritmética binary80, CW/SW/TOP/tags ni se reactiva el transform double bloqueado.

## Comparación real de enlace

A y B contienen normal-f2d y outlining x87; **no** son la APK pública sin outlining. El efecto de outlining y el de ICF no se confunden. Solo se cambia la opción de enlace sobre los mismos objetos:

| Propiedad | A: metadata, ICF OFF | B: metadata, ICF safe |
| --- | ---: | ---: |
| `.text` | 40.265.212 bytes | 40.251.592 bytes |
| `libmain.so` empaquetada | 45.353.272 bytes | 45.336.488 bytes |
| Direcciones únicas del helper push | 12 | 1 |
| Direcciones únicas del helper pop | 12 | 1 |
| Exportaciones definidas | 490 | 490 |

Reducción: **13.620 bytes de código y 16.784 bytes de biblioteca empaquetada**. Los 37 objetos presentes en el directorio de `main` y las 28 fuentes generadas conservan sus hashes entre A/B. El enlace B ejecutó únicamente `[1/1] Linking`, sin recompilar. En p4, las 42 secciones ejecutables conservaron sus bytes al añadir la metadata. No se introducen instrucciones, conversiones ni spills por emitirla; las direcciones y relocaciones finales sí cambian con el enlace.

Las 490 exportaciones conservan nombre, tipo, binding, visibilidad y tamaño. Los APK difieren únicamente en `lib/arm64-v8a/libmain.so`, descontando `META-INF/` de firma. Se verificaron ABI AArch64, firma y alineación de 16 KiB mediante el empaquetador existente. Recursos, otras bibliotecas y código Java/Dex coinciden por contenido.

- APK A SHA256: `5e64207ed641fa5c7ed3e3407dcfb3c20f57922399b3ad54b2ac502dee3c0e00`.
- APK B SHA256: `4f1e74f6d5829e9bcabef78f4f5c4590b8325749a6a627153397265f85648fe1`.

Esto reduce almacenamiento de instrucciones duplicadas; **no reduce el número de instrucciones ejecutadas por cada copia** ni demuestra una ganancia FPS, de caché o de latencia. La localidad de llamadas también debe medirse físicamente. Cualquier perfil futuro necesita el ELF/Build ID nuevo: los PC de perfiles previos no son reutilizables directamente.

## Equivalencia y regresión

`tools/recomp/diagnostics/verify_arm64_x87_shifts.py` compila código AArch64 real con el NDK y lo ejecuta en Unicorn. Contrasta la secuencia original de copias y dos unidades con helpers outlined frente a un modelo independiente de bytes. Resultado final: **6.000 llamadas sin ICF y 6.000 con safe ICF**, 1.000 estados por dirección, 16 alineaciones, cero discrepancias. Comprueba R completo, padding, extensiones de escritura, guardas, FPCR/FPSR, retorno y SP. No ejecuta aritmética x87 ni faltas de RAM guest; no constituye equivalencia integral del juego ni un benchmark TECNO.

La revisión independiente no encontró bloqueos de integración. Sus dos observaciones se corrigieron: el auditor rechaza Python `-O/-OO` antes de producir archivos y el contador de alineaciones refleja los casos realmente ejecutados. La ejecución adicional de cuatro casos informa cuatro alineaciones y 24 llamadas.

- Suite Python local final: **491 pruebas, seis omitidas, cero fallos**.
- Diferencial del generador existente a O0/O1/O2: aprobado, R/RAM/U/PC.
- Control CTest durante el bloque: **40/40**.
- Compilación y enlace nativos sin advertencias nuevas; Java mantiene las cuatro advertencias conocidas de `source/target 8` y bootstrap class path.

## Vías descartadas y reversión

La sustitución aislada `rd/wr` binary80 por dos copias 8+2 genera las mismas cuatro cargas/escrituras AArch64: no se añadió código redundante.

Un helper externo oculto único también pasó equivalencia y produjo APK, pero empeoró p4: **1.821.220 → 1.831.372 bytes de funciones**, con **2.539 instrucciones estáticas adicionales**, incluidos 417 ADRP y 402 LDR adicionales. No se atribuye tiempo CPU exclusivo a esos conteos. Se retiró completamente del producto; parche, código, ensamblador y APK negativos se conservan solo como evidencia privada. Safe ICF evita cambiar esa frontera de compilación.

Se restauraron exactamente las doce particiones CoDSP originales por hash, los dos flags CMake quedaron OFF y se repusieron APK pública 0.2.4 y ELF correspondientes tras comprobar el hash de su biblioteca stripped. La caché de objetos experimentales requiere reconstrucción al volver a una build normal; no se presenta como una nueva build pública. No se instaló nada ni se tocaron partidas o datos del dispositivo.

## Reproducción y siguiente bloque

Con los privados autorizados y SDK/NDK instalados:

~~~powershell
# A: referencia con outlining y metadata, sin ICF
python tools/recomp/build_android.py --abi arm64-v8a --recomp-opt 1 --x87-normal-f2d --x87-stack-shift-outline --arm64-icf-metadata
# B: misma familia, safe ICF activado
python tools/recomp/build_android.py --abi arm64-v8a --recomp-opt 1 --x87-normal-f2d --x87-stack-shift-outline --arm64-icf-metadata --arm64-safe-icf
# Volver al preset normal; restaura fuentes y desactiva las opciones
python tools/recomp/build_android.py --abi arm64-v8a --recomp-opt 1 --x87-normal-f2d
~~~

Para reproducir el oráculo, usar `verify_arm64_x87_shifts.py --llvm-bin RUTA_NDK_BIN --out RUTA_SESION_NUEVA --icf none` y después `--icf safe` con otro destino. La ruta de salida debe pertenecer a `.local/profiles/runs/`; los directorios existentes se rechazan.
